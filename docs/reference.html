batch(requests)[source]¶

Send multiple requests in a single batch.

This is more efficient than individual requests for high-throughput scenarios because it amortizes FFI call overhead across all requests. Requests are executed in parallel on the Go side.

Parameters:

requests (list[dict]) – List of request dictionaries. Each dict should contain: - url (required): Target URL - method (required): HTTP method (GET, POST, etc.) - params (optional): Query parameters - data (optional): Form data or raw body - json_data (optional): JSON data (auto-serialized) - headers (optional): Custom headers - And any other CycleTLS options (ja3, proxy, timeout, etc.)

Return type:

list[Response]

Returns:

List of Response objects in the same order as input requests.

Raises:

CycleTLSError – If the client is closed or batch request fails.

Example

>>> with CycleTLS() as client:
...     responses = client.batch([
...         {"url": "https://api.example.com/users", "method": "GET"},
...         {"url": "https://api.example.com/posts", "method": "GET"},
...         {"url": "https://api.example.com/data", "method": "POST", "json_data": {"key": "value"}},
...     ])
...     for resp in responses:
...         print(resp.status_code)

    • local_address: local IP address to bind the outgoing TCP connection to (useful on multi-homed hosts)

    • timeout: request timeout in seconds

    • insecure_skip_verify: skip TLS certificate verification

    • enable_connection_reuse: reuse persistent connections (default True)

Response object with status, headers, body, cookies, etc.

Response

>>> response = client.get("https://example.com", fingerprint="chrome_120")

A session object that maintains persistent cookies and headers.

Similar to requests.Session, this class extends CycleTLS to provide automatic cookie and header persistence across requests.

Persistent cookie jar shared across requests

Persistent headers sent with all requests

Type:

Base URL prepended to relative URLs

Type:

Optional[str]

Type:

Optional[Tuple[str, str]]

Example

>>> with Session() as session:
...     # Set persistent headers
...     session.headers['Authorization'] = 'Bearer token123'
...
...     # Login - cookies are automatically saved
...     session.post('/login', json_data={'user': 'admin', 'pass': 'secret'})
...
...     # Subsequent requests include cookies and headers automatically
...     response = session.get('/profile')

class cycletls.CaseInsensitiveDict(data=None, **kwargs)[source]¶

A case-insensitive dict-like object.

Implements all methods and operations of MutableMapping as well as dict’s .copy(). All keys are expected to be strings. The structure remembers the case of the last key to be set, and iter(instance), keys(), items(), iterkeys(), and iteritems() will contain case-sensitive keys. However, querying and contains testing is case insensitive:

cid = CaseInsensitiveDict()
cid['Accept'] = 'application/json'
cid['aCCEPT'] == 'application/json'  # True
list(cid) == ['Accept']  # True

For example, headers['content-encoding'] will return the value of a 'Content-Encoding' response header, regardless of how the header name was originally stored.

If the constructor, .update, or equality comparison operations are given keys that have equal .lower() values, the behavior is undefined.

class cycletls.WebSocketConnection(url, headers=None, ja3=None, user_agent=None, proxy=None, timeout=30)[source]¶

A WebSocket connection with TLS fingerprinting support.

This class provides both synchronous and asynchronous APIs for WebSocket communication. It supports context managers for automatic cleanup.

Parameters:

  • url (str) – WebSocket URL (ws:// or wss://)

  • headers (Optional[Dict[str, str]], default: None) – Optional headers to include in the handshake

  • ja3 (Optional[str], default: None) – Optional JA3 fingerprint for TLS

  • user_agent (Optional[str], default: None) – Optional User-Agent header

  • proxy (Optional[str], default: None) – Optional proxy URL

  • timeout (int, default: 30) – Connection timeout in seconds

Example

>>> # Synchronous usage
>>> ws = WebSocketConnection("wss://echo.websocket.org")
>>> ws.connect()
>>> ws.send("Hello")
>>> msg = ws.receive()
>>> ws.close()
>>>
>>> # Context manager
>>> with WebSocketConnection("wss://echo.websocket.org") as ws:
...     ws.send("Hello")
...     msg = ws.receive()
>>>
>>> # Async context manager
>>> async with WebSocketConnection("wss://stream.example.com") as ws:
...     await ws.send_async("Hello")
...     msg = await ws.receive_async()

class cycletls.SSEConnection(url, headers=None, ja3=None, user_agent=None, proxy=None, timeout=30, last_event_id=None)[source]¶

A Server-Sent Events connection with TLS fingerprinting support.

This class provides both synchronous and asynchronous APIs for SSE streams. It supports automatic reconnection and Last-Event-ID tracking.

Parameters:

  • url (str) – SSE endpoint URL

  • headers (Optional[Dict[str, str]], default: None) – Optional headers to include in the request

  • ja3 (Optional[str], default: None) – Optional JA3 fingerprint for TLS

  • user_agent (Optional[str], default: None) – Optional User-Agent header

  • proxy (Optional[str], default: None) – Optional proxy URL

  • timeout (int, default: 30) – Connection timeout in seconds

  • last_event_id (Optional[str], default: None) – Optional Last-Event-ID for reconnection

Example

>>> # Synchronous iteration
>>> with SSEConnection("https://api.example.com/events") as sse:
...     for event in sse:
...         if event.event == "update":
...             print(event.data)
>>>
>>> # Async iteration
>>> async with SSEConnection("https://api.example.com/events") as sse:
...     async for event in sse:
...         print(f"[{event.event}] {event.data}")
